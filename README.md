# 🚛 LogixFleet Website

A modern and responsive website for **LogixFleet**, showcasing its fleet management solutions, services, and digital capabilities.

The website provides LogixFleet with a professional online presence and helps potential clients understand the company's services, explore its fleet management solutions, and contact the team for more information.

## 🏢 About LogixFleet

LogixFleet is a fleet management-focused platform designed to help businesses improve the way they manage vehicles, drivers, and day-to-day fleet operations.

A fleet management solution can support organizations by helping them monitor vehicles, organize fleet information, improve operational visibility, and make better decisions based on fleet data.

This website serves as the public-facing platform for presenting LogixFleet's services and communicating with current and potential customers.

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/) version 18 or later.
- npm, which is included with Node.js.
- Git.

You can confirm your installed versions by running:

```bash
node --version
npm --version
git --version
```

### Clone the Repository

```bash
git clone https://github.com/Briankiboi/logixfleet-website-v1.git
```

### Navigate to the Project Directory

```bash
cd logixfleet-website-v1
```

### Install Dependencies

```bash
npm install
```

## 💻 Run the Project Locally

Start the Vite development server:

```bash
npm run dev
```

Vite will provide a local development URL, usually:

```text
http://localhost:5173
```

Open the URL in your browser to view the website.

The page will automatically reload when you make changes to the source code.

## 🌐 Deployment

The application can be deployed to any platform that supports modern frontend applications and static websites.

Recommended deployment platforms include:

- [Vercel](https://vercel.com/)
- [Netlify](https://www.netlify.com/)
- [GitHub Pages](https://pages.github.com/)
- Cloud hosting platforms
- Other static hosting providers

### Deploying with Vercel

1. Push the project to GitHub.
2. Sign in to Vercel.
3. Import the `logixfleet-website-v1` repository.
4. Select the appropriate project settings.
5. Deploy the application.
6. Add a custom domain if one is available.

For continuous deployment, connect the GitHub repository to the hosting platform. New changes pushed to the main branch can then be deployed automatically.
